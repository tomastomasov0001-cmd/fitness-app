2. UCEL APLIKACE
================================================================================
Aplikace pro sledovani treninku s nasledujicimi funkcemi:

- Treningove varianty (napr. "Nohy", "Hrudnik", "Push day") - neomezeny pocet
- Cviky v kazde variante - neomezeny pocet
- Sledovani pri treninku: serie, opakovani, vaha
- Kalendar pro prirazeni variant ke dnum
- Obrazky a videa u cviku
- Historie treninku

4. DATOVY MODEL (Room Database)
================================================================================

WorkoutVariant (workout_variants)
---------------------------------
- id: Long (PK, auto)
- name: String
- description: String
- createdAt: Long (timestamp)

Exercise (exercises)
--------------------
- id: Long (PK, auto)
- name: String
- description: String
- imagePath: String? (cesta k obrazku)
- videoPath: String? (cesta k videu)
- createdAt: Long

VariantExercise (variant_exercises)
-----------------------------------
- variantId: Long (FK -> WorkoutVariant)
- exerciseId: Long (FK -> Exercise)
- orderIndex: Int (poradi cviku ve variante)
- PK: (variantId, exerciseId)

WorkoutLog (workout_logs)
-------------------------
- id: Long (PK, auto)
- variantId: Long (FK -> WorkoutVariant)
- date: Long (datum treninku)
- notes: String
- completed: Boolean
- createdAt: Long

ExerciseSet (exercise_sets)
---------------------------
- id: Long (PK, auto)
- workoutLogId: Long (FK -> WorkoutLog)
- exerciseId: Long (FK -> Exercise)
- setNumber: Int (cislo serie 1, 2, 3...)
- reps: Int (pocet opakovani)
- weight: Float (vaha v kg)
- completed: Boolean
