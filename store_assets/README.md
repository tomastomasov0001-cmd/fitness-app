## Potřebné soubory

### 1. Ikona (povinné)
- **Zdrojový soubor:** `icon_option1_dumbbell.svg` ✓
- **Cílový soubor:** `icon_512.png`
- **Rozměry:** 512 x 512 px
- **Formát:** PNG (32-bit, bez průhlednosti)

### 2. Feature Graphic (povinné)
- **Název:** `feature_graphic.png`
- **Rozměry:** 1024 x 500 px
- **Formát:** PNG nebo JPG

### 3. Screenshoty (povinné, min 2)
- **Názvy:** `screenshot_1.png`, `screenshot_2.png`, ...
- **Rozměry:** 16:9 nebo 9:16 (např. 1080x1920)
- **Formát:** PNG nebo JPG

## Jak převést ikonu SVG na PNG 512x512

### Možnost 1: Online konvertor (nejrychlejší)
1. Otevři https://svgtopng.com nebo https://cloudconvert.com/svg-to-png
2. Nahraj `icon_option1_dumbbell.svg`
3. Nastav rozměry 512x512
4. Stáhni a ulož jako `icon_512.png`

### Možnost 2: Android Studio
1. File → New → Image Asset
2. Asset Type: Launcher Icons
3. Source Asset → Path: vyber `icon_option1_dumbbell.svg`
4. Finish

### Možnost 3: Figma/Canva
1. Importuj SVG
2. Exportuj jako PNG 512x512

## Jak vytvořit Feature Graphic

Doporučený obsah:
- Název aplikace: "Fitness App"
- Krátký slogan: "Sledujte své tréninky"
- Obrázek telefonu s aplikací
- Barvy odpovídající ikoně

Online nástroje:
- https://www.canva.com (šablony "Google Play Feature Graphic")
- https://www.figma.com

## Jak udělat screenshoty

1. Spusť aplikaci na emulátoru nebo telefonu
2. Udělej screenshot klávesami:
   - Emulátor: tlačítko fotoaparátu v ovládacím panelu
   - Telefon: Power + Volume Down
3. Doporučené obrazovky:
   - Hlavní obrazovka (kalendář)
   - Seznam tréninků
   - Detail tréninku s cviky
   - Aktivní trénink
   - Statistiky
