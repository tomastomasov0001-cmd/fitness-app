Zásady ochrany soukromí

Poslední aktualizace: Srpen 2025

1. Úvod

Aplikace Fitness App ("my", "naše", "aplikace") respektuje vaše soukromí. Tyto zásady popisují, jaké informace shromažďujeme a jak je používáme.

2. Jaké údaje shromažďujeme

Aplikace Fitness App shromažďuje a ukládá následující údaje pouze lokálně na vašem zařízení:

  • Názvy a popisy vašich tréninků
  • Názvy a popisy cviků
  • Záznamy o trénincích (datum, série, opakování, váha, čas)
  • Nastavení aplikace (jazyk, preference)

3. Jak používáme vaše údaje

Všechny údaje jsou používány výhradně pro:

  • Zobrazení vašich tréninků a statistik
  • Sledování vašeho pokroku
  • Export a import dat (pouze na vaše vyžádání)

4. Sdílení údajů

Vaše data nesdílíme s žádnými třetími stranami. Všechna data zůstávají pouze na vašem zařízení.

5. Ukládání dat

Všechna data jsou uložena lokálně na vašem zařízení v zabezpečené databázi. Data nejsou odesílána na žádné servery.

6. Vaše práva

Máte plnou kontrolu nad svými daty:

  • Můžete kdykoli smazat jednotlivé tréninky nebo cviky
  • Můžete exportovat všechna data do souboru
  • Odinstalací aplikace smažete všechna data

7. Děti

Aplikace není určena pro děti mladší 13 let. Vědomě neshromažďujeme údaje od dětí.

8. Změny zásad

Tyto zásady můžeme příležitostně aktualizovat. O významných změnách vás budeme informovat prostřednictvím aplikace.
